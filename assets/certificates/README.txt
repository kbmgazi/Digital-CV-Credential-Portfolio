CERTIFICATE IMAGES
===================

Place your certificate image files in this folder.

Recommended format: JPG or PNG
Recommended naming: lowercase, hyphen-separated, matching the "image"
field you set for that certification in js/script.js

Examples:
  aws-cloud-practitioner.jpg
  istqb-foundation.jpg
  java-foundation.jpg
  itil-foundation.jpg

After adding an image here, open js/script.js and set the matching
certification's "image" field to:
  assets/certificates/your-file-name.jpg

A placeholder file (certificate-placeholder.jpg) is referenced by the
example certification records until you replace it.
